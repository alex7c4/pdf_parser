# The task
Create a WEB application that will convert user uploaded PDFs to Markdown (or plain text) and provide a summary from extracted text.
Using an upload form/button from Web page users can upload one or several PDFs from a WEB page interface.
WEB application accepts any PDF and parses it to a markdown (or text) using one of the following methods (let the user decide):
- PyPDF (no Markdown, just plain text)
- Google Gemini Flash 2.5 (to markdown) (default choice)
- Mistral OCR (to markdown)

Try to extract text from images, tables or graphics.
Limit files to PDF only and max size to 25mb per file.
Summary of the PDF should be about 500-600 characters.

Processing should be done asynchronically. Limit concurrent parallel processing to 5 documents only - rest should be queried.
The total number of files that can be uploaded at one time should be less than or equal to 50.
If PDF is not correct or is protected - show an error message.
UI WEB interface should be simple and lightweight.

After markdown/text is extracted from PDF - a summary of the document should be generated by Google Gemini Flash in a markdown format.
Extracted text, summary and original PDF should be put in Redis DB (Use Redis Streams feature of Redis as a queue to asynchronously process uploaded documents).
Save hash of the original PDF and re-use existing text and summary if the same PDF was uploaded.
Show last 10 items history of PDFs documents with a generated summary.

## Global config
Project name should be `pdf_parser`.
Add possibility to run Python code locally for development.
Use type-hinting for backend and frontend.
Line Length should be 120.
Use PEP8 rules for Python code formating, sort imports according to PEP8.
Add unit tests using `pytest` for backend code.
For backend code - add a possibility to test functions/methods with unit tests. 

## Backend
Backend tools:
- Python 3.14
- FastAPI `fastapi==0.121.2`
- Redis 8+ Python client version 6.3.* (Redis Streams feature).
- PyPDF 6.3.* Python client.
- Google Gemini Flash 2.5 API (Python client, version of `google-genai`).
- Mistral OCR (Python Client, version `mistralai==1.9.*`).

Wrap all application components in Docker Compose.

## Frontend
Frontend tools:
- Javascript OR Typescript with React OR Next.JS (choose something simple).
- You can use API polling, websockets or SSE to display summarization results once they are ready (choose something simple).
